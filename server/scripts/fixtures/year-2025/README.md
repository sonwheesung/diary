# 1년치 더미 일기 — 직장인 · 2025년

> **용도**: 주간 → 월간 → 연간 **연쇄 생성**을 실제로 돌려본다.
> 지금까지 시험한 것은 주간뿐이고(`../README.md` 페르소나 9종), 월간·연간은
> **코드는 있는데 한 번도 안 돌아봤다.**

```bash
OPENAI_API_KEY=... node --experimental-strip-types server/scripts/run-year.mjs
```

---

## 왜 2025년인가

**2026이 아니다.** `isClosed('2026')`가 `false`다 — 안 끝난 해는 앱이 연간을 못 만든다(§6.5).
2025는 끝났고 백필 지평(`backfillFloor` = 작년 1월 1일 = **2025-01-01**) 안에 있어서,
**앱에서 실제로 만들 수 있는 조합**과 같다. 시험이 실물과 어긋나면 시험이 아니다.

```
2025 = 12개월 · 52주
호출  주간 52 + 월간 12 + 연간 1 = 65회   (리포트 1건 ≈ ₩1)
```

---

## 🔴 왜 합성 월간을 쓰지 않았나

처음엔 *"8월 한 달만 진짜로 만들고 나머지 11개월은 월간 리포트를 손으로 지어내자"* 고 했다.
그러면 **연간이 시험하는 것이 "모델이 쓴 월간"이 아니라 "내가 쓴 월간"** 이 된다.
연간은 이 상품의 최종 가치인데 입력이 가짜면 결과를 믿을 수 없다.

원가가 ₩75 수준이라 아낄 이유가 없었다. **전부 연쇄로 만든다.**

한 사람의 한 해다. 이름은 쓰지 않는다(일기는 자기에게 쓰는 글이라 자기 이름을 안 쓴다).

|---|---|---|

| 2 | 설·가족. 회사는 조용. 커피 잔 수가 늘기 시작 | **반복**의 씨앗 |
| 3 | 조직 개편 소문. 어깨 통증 첫 등장 | 불안의 시작 |
| 4 | 새 팀장 부임. *"그건 원래 그렇게 하는 거예요"* | **인용** — 이후 반복 등장 |
| 5 | 큰 프로젝트 투입. 운동 이야기가 **사라진다** | **변화**(1월 대비) |
| 6 | 번아웃 조짐. 주말에 잠만. 사람 이야기가 줄어든다 | **고립**의 점진 |
| 7 | 마감 성공. 🔴 감정 태그 `joy`인데 본문은 공허 | **어긋남** |
| 8 | 휴가 — **일기가 비는 주가 있다**. 돌아와 이직 생각 | **비어있음** |
| 9 | 이직 준비. 회사 얘기가 줄고 *"요즘"* 이 는다 | 화제 이동 |
| 10 | 면접. 긴장과 기대 | 톤 상승 |

### 반복 어휘 (연간이 이걸 줍는지가 시험이다)

`커피` · `어깨` · `지하철 창밖` · `그냥` · `원래 그렇게`

### 빈 날

일기는 **매일 쓰지 않는다.** 주 4~6개가 보통이고, 8월 휴가 주와 11월 탈락 직후에는 더 준다.
`missingDays` 경로도 함께 시험된다.
