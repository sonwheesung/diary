# 1년치 더미 일기 — **아무 일도 없는 해** · 2026년

> `year-2025/`는 잘 설계된 해였다. 팀장이 바뀌고, 프로젝트가 끝나고, 이직에 떨어졌다.
> **관찰거리를 일부러 심었고 서사에 호가 있었다.**
>
> 🔴 **실제 사용자의 1년은 이렇게 친절하지 않다.** 이 fixture는 그 반대를 시험한다.

```bash
OPENAI_API_KEY=... node --experimental-strip-types server/scripts/run-year.mjs 2026
```

---

## 이 시험이 묻는 것

**사건이 없을 때 리포트가 무엇을 하는가.** 셋 중 하나로 갈린다.

| | |
|---|---|
| 🔴 **지어낸다** | 없는 사건을 만든다. **최악.** 사용자가 즉시 알아채고 신뢰가 끝난다 |
| 🟡 **빈말을 한다** | *"평온한 한 해였습니다"* 류. 나쁘지만 안 위험하다 |
| ✅ **느린 변화를 찾는다** | 사건이 아니라 **결**이 바뀐 것을 본다. 이게 되면 상품이다 |

⚠ 그리고 정직하게 *"이 주에는 쓸 말이 많지 않습니다"* 라고 할 수 있는지도 본다.
   짧게 끝내는 것이 채워 넣는 것보다 낫다는 지시가 실제로 작동하는지.

---

## 누구인가

**프리랜서 번역가 · 혼자 삶 · 고양이 한 마리 · 재택.**

직장이 없어 팀장도 인사이동도 없다. 연애도 이사도 없다. 매달이 거의 같다.

---

## 🔴 넣지 않은 것

이 목록이 이 fixture의 정의다.

- 사건이 **하나도 없다** — 합격·불합격, 만남·헤어짐, 이사, 병, 여행, 승진, 사고
- **다짐도 없다.** *"올해는 운동을"* 같은 문장은 그 자체로 사건이다(`year-2025/`가 그걸로 시작했다)
- **극적인 감정이 없다.** `angry`가 한 해에 한 번뿐이고 그것도 택배 때문이다
- 마지막 날에 **한 해를 돌아보지 않는다.** 12/31이 12/30과 다를 게 없다 —
  그게 아무 일도 없는 해의 정직한 끝이다

---

## 심은 것 — 전부 **느린 것**

사건이 아니라 **1년을 나란히 놓아야만 보이는 것**들이다. 하루씩 읽으면 아무것도 아니다.

| | 무엇 | 어떻게 |
|---|---|---|
| ① | **글이 짧아진다** | 1월 4~5문장 → 12월 1~2문장. **일기 자체가 증거다** |
| ② | **고양이가 앞으로 나온다** | 2월에 한 줄 스치듯 → 10월엔 가장 자주 나오는 이름 |
| ③ | **잠드는 시간이 밀린다** | 5월 12시 반 → 11월 2시. 가끔만 적힌다 |
| ④ | **밖이 줄어든다** | 극적인 고립이 아니라 그냥 덜 나간다 |
| ⑤ | **계절만 확실히 변한다** | 창밖 나무 한 그루가 1년 내내 나온다 |
| ⑥ | *"똑같다"* | 7월에 처음 나오고 반복된다. **그 밑의 결이 바뀐다** — 안도 → 지루함 → 수용 |

### 🔴 함정 두 개

**⑦ 3월과 9월이 거의 같다.** 소재·구조·날씨까지 짝을 맞췄다.
   *"3월과 9월이 거의 같은 달이었다"* 를 짚으면 **아무도 스스로 못 하는 관찰**이다.
   연간이 이걸 잡으면 이 기능의 값이 증명된다.

**⑧ 8월은 거의 안 썼다.** 5개, 전부 한 줄. 주에 하나뿐인 주가 나온다.
   주간 리포트가 **패딩하는지 정직하게 짧은지**를 본다.

---

## ⚠ 2026은 아직 안 끝난 해다

`isClosed('2026')`가 `false`라 **앱에서는 2026 연간을 만들 수 없다**(2027-01-01부터 가능).
이 fixture는 **프롬프트 시험 전용**이다 — 스크립트가 서버 라우트를 안 거치므로 상관없다.

`year-2025/`가 *"시험이 실물과 어긋나면 시험이 아니다"* 라며 2025를 고른 것과 다른 판단이다.
거기서 시험한 것은 **앱이 만들 수 있는 조합**이었고, 여기서 시험하는 것은 **프롬프트**다.
