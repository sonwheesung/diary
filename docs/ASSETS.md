# ASSETS — 이미지 에셋과 생성 프롬프트

> 디자인 시안(2026-08-07 수령)에서 필요한 이미지 에셋 목록과 AI 생성 프롬프트.
> 코드로 그리는 게 나은 것과 이미지로 만들 것을 먼저 가른다 — 전부 이미지로 만들면 앱이 무거워지고
> 다크모드·해상도 대응이 안 된다.

---

## 1. 이미지로 만들지 **않는** 것 (코드/SVG로 그린다)

| 요소 | 방법 | 이유 |
|---|---|---|
| 감정 아이콘 5종 | SVG(react-native-svg) | 색·크기·선택 상태가 동적으로 바뀐다. 이미지로 하면 상태별로 5×N장이 필요 |
| 하단 네비 아이콘(홈·캘린더·+·검색·설정) | Lucide | 이미 스택에 있음. 다크모드 색 반전이 공짜 |
| 저장 완료 체크 원형 | SVG + 애니메이션 | 등장 연출이 필요한데 이미지로는 못 함 |
| 파란 원형 도형(홈·작성 화면 배경 장식) | `View` + borderRadius | 단색 원. 이미지로 만들 이유가 없다 |
| 캘린더 날짜 점 | View | 감정 색을 코드에서 매핑 |
| 카드·버튼·구분선 | 스타일 | |

## 1.5 실제로 만든 것 (2026-08-09) — 코드로 그렸다

아이콘·스플래시는 **AI 일러스트 대신 코드로 그렸다**(`scripts/make-assets.py`, Pillow).
`python scripts/make-assets.py` 로 언제든 다시 뽑는다.

**왜 코드인가**
- 조각의 언어가 "Apple 수준 미니멀 · Glass 금지 · 과한 Gradient 금지 · Shadow 최소"(§9)라
  기하학적 마크가 타협이 아니라 정답에 가깝다.
- **수채 일러스트는 48px 런처에서 뭉개진다.** 형태를 셋으로 제한해 작은 크기에서도 읽히게 했다.
- 색을 바꾸려면 스크립트 상수만 고치면 된다. 팔레트 정본과 어긋나면 거기서 바로 보인다.

**마크**: 겹쳐 놓인 종이 조각 세 장 — "하루가 조각으로 쌓인다"는 한 줄 요약 그대로.

| 파일 | 쓰임 | 비고 |
|---|---|---|
| `icon.png` 1024 | iOS·기본 아이콘 | 배경 채움(iOS는 투명 불가) |
| `adaptive-icon.png` 1024 | 안드로이드 적응형 전경 | 투명. 내용을 **가운데 66% 원** 안에 둠 |
| `splash-icon.png` 1024 | 스플래시(라이트) | 투명. 배경색은 플러그인이 칠함 |
| `splash-icon-dark.png` 1024 | 스플래시(다크) | ⚠ 아래 참고 |
| `favicon.png` 48 | 웹 | 지금 웹은 안 쓰지만 없으면 expo가 경고 |

⚠ **다크용 마크를 따로 둔 이유**: 라이트 색을 그대로 쓰면 **앞의 남색 조각이 다크 배경에 묻힌다.**
다크 팔레트에서 강조색 명암을 뒤집은 것과 같은 문제다(§9). 앞 조각을 `accent`(#8AB0E8)로 올리고
가운데를 한 단계 내려 셋이 구분되게 했다. 실기기(에뮬)에서 라이트·다크 둘 다 확인함.

⏭ 아래 AI 프롬프트는 **살려둔다.** 나중에 수채 방향으로 갈아끼우고 싶어지면 그대로 쓴다.
   다만 그때도 **48px에서 읽히는지**를 먼저 본다.

## 2. AI로 생성할 것

공통 지시사항 — **모든 프롬프트에 붙인다.**

```
스타일: 미니멀 수채화 일러스트, 부드러운 질감, 손그림 느낌
색상: 차분한 블루(#4A6FA5, #7B9BC4, #A8C0D9) + 크림/베이지(#EFE7DA, #F5F1E8) + 흰 여백
금지: 진한 채도, 강한 그라데이션, 광택/글래스 효과, 짙은 그림자, 텍스트/글자, 사람 얼굴
배경: 완전한 흰색 또는 투명
여백을 넉넉히 두고, 화면 중앙에 요소 하나만 배치
```

---

### A. 앱 아이콘 (1024×1024, 필수)

```
정사각형 앱 아이콘. 크림색 종이 조각 여러 장이 살짝 겹쳐 콜라주처럼 모여 있는 모습을
위에서 내려다본 구도. 종이 조각 중 하나에는 옅은 하늘색 수채 얼룩이 번져 있고,
다른 하나에는 작은 들꽃 한 송이가 가는 선으로 그려져 있다.
배경은 아주 옅은 블루그레이 단색. 아이콘 가장자리에 충분한 여백.
미니멀 수채화, 부드러운 질감, 텍스트 없음, 로고 없음.
```

> 안드로이드 적응형 아이콘은 전경/배경을 분리해야 한다. 위 이미지를 전경(종이 조각만, 투명 배경)과
> 배경(단색 #EFF2F7)으로 나눠 각각 저장한다.

### B. 스플래시 (1284×2778 또는 중앙 배치용 정사각 512)

```
세로 화면 중앙에 크림색 종이 조각 하나가 놓여 있고, 그 위로 옅은 하늘색 수채 물감이
살짝 번져 있는 모습. 주변은 아주 옅은 블루그레이 배경에 여백만 넓게.
아주 조용하고 잔잔한 분위기. 텍스트 없음.
```

### C. 빈 상태 일러스트 3종 (각 600×600, 투명 배경)

**C-1. 아직 조각이 없을 때 (홈)**
```
빈 크림색 종이 한 장이 마스킹 테이프로 붙어 있고, 그 옆에 작은 들꽃 한 송이가
가는 선으로 그려진 모습. 종이는 비어 있다. 조용하고 시작을 기다리는 느낌.
투명 배경, 미니멀 수채화.
```

**C-2. 검색 결과 없음**
```
작은 돋보기와 크림색 빈 종이 조각 몇 장이 흩어져 있는 모습.
돋보기는 가는 선으로만 그린다. 쓸쓸하지 않고 담담한 분위기.
투명 배경, 미니멀 수채화.
```

**C-3. 이번 달 기록 없음 (캘린더)**
```
빈 달력 격자가 아주 옅은 선으로 그려져 있고 그 위에 작은 구름 하나가
떠 있는 모습. 격자에는 아무 표시도 없다. 투명 배경, 미니멀 수채화.
```

### D. 장식 일러스트 (홈·작성·상세 화면 콜라주용)

시안의 홈/상세 화면 상단에 있는 **꽃·식물 그림 조각**이다. 사진 자리는 사용자 사진이 들어가므로
생성하지 않는다.

**D-1. 들꽃 라인 드로잉 (400×600, 투명 배경)**
```
크림색 종이 위에 가는 선으로 그려진 들꽃 한 줄기. 잎은 서너 장, 꽃송이는 작게.
수채 물감이 아주 옅게 번져 있다. 종이 위쪽 모서리에는 반투명 마스킹 테이프가
비스듬히 붙어 있다. 투명 배경, 미니멀 식물 세밀화.
```

**D-2. 하늘/구름 수채 조각 (600×400, 투명 배경)**
```
옅은 하늘색 수채로 그린 뭉게구름 한 조각. 경계가 부드럽게 번져 있고
아래쪽은 흰색으로 자연스럽게 사라진다. 사진이 아니라 수채화.
투명 배경.
```

**D-3. 마스킹 테이프 조각 (300×120, 투명 배경, 3~4종 변형)**
```
반투명 마스킹 테이프 한 조각. 크림색과 아주 옅은 하늘색 두 가지 버전.
가장자리가 손으로 찢은 듯 불규칙하다. 정면에서 본 모습, 그림자 없음.
투명 배경.
```

**D-4. 종이 질감 (1000×1000, 타일 가능)**
```
아주 미세한 결이 있는 크림색 종이 질감. 무늬나 패턴 없이 질감만.
균일한 밝기, 이음매 없이 반복 가능한 타일. 매우 은은해서 거의 보이지 않을 정도.
```

## 3. 생성 후 처리

1. **투명 배경 필수 항목**(C·D)은 PNG로 받고, 배경이 흰색으로 들어오면 제거한다.
2. **앱 아이콘·스플래시**는 크기별로 리사이즈한다 — Expo가 `app.json`에서 자동 생성해주는 범위를 확인하고,
   부족한 것만 직접 만든다.
3. **용량**을 확인한다. 장식 일러스트는 화면당 1~2장이므로 각 200KB 이하를 목표로 한다
   (폰트가 이미 4.5MB를 쓰고 있다 — 에셋까지 부풀면 설치 용량이 체감된다).
4. 생성 결과가 시안 톤과 어긋나면 **색상 지시를 더 강하게** 준다. AI는 채도를 올리는 경향이 있다.
